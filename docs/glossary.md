# 用語（繁體中文介面）

| 用這個 | 不要用 |
|---|---|
| 即時動態 | Live Activity、即時活動 |
| 動態島 | 靈動島 |
| 小工具 | Widget |
| 鎖定畫面 | 鎖屏 |
| 選擇歌詞 | 換歌詞 |
| 歌詞提前（正值 = 歌詞早一點出現） | offset、延遲（在介面上） |
| 診斷 | 除錯 |
| 專注模式 | 車架模式（說明文字可用） |
| 定位保活 | location keep-alive、背景定位 |
| 上車提醒 | 通知提醒、push |
| 卡拉 OK 視窗（CarPlay 卡片上「目前句 + 接下來幾句，每句一條進度條」） | 歌詞列表 |
| 離開寬限（車用音訊離開後等 30 秒） | debounce |

規則：測試與範例不得包含任何真實歌詞，一律用「測試第 N 句」「示範歌詞」這類自編字串。
